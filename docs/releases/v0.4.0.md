# ryzen-smu-cli v0.4.0

This release adds a stable read-only telemetry interface for CurveAlign's
Professional and Ultimate stress-test views. Existing v0.3.5 command output
contracts remain unchanged; the combined stream is a separate versioned JSON
Lines protocol.

## CPU temperature

`--get-cpu-temperature` reads the CPU Tctl/Tdie thermal-control register and
prints one invariant-culture value:

```text
Current CPU temperature: 71.875 C.
```

Families 17h, 19h, and 1Ah use the fixed read-only SMN thermal register. The
decoder handles the temperature range bit and legacy Ryzen/Threadripper Tctl
offsets, and rejects sentinel or implausible values. The implementation uses
ZenStates-Core's signed PawnIO read-only port directly so low-level mutex
diagnostics cannot contaminate stdout.

## Atomic JSON Lines telemetry

Start the combined stream with:

```powershell
.\ryzen-smu-cli.exe --stream-telemetry
.\ryzen-smu-cli.exe --stream-telemetry --interval-ms 500
```

The default is 500 ms and the accepted range is 100 through 60000 ms. Each
flushed stdout line contains exactly one schema-1 object:

```json
{"kind":"telemetry","schemaVersion":1,"sequence":0,"elapsedMilliseconds":7,"timestampUtc":"2026-08-10T08:30:00.1234567+00:00","vcoreVolts":1.225,"cpuTemperatureCelsius":71.875,"temperatureSource":"tctl-tdie"}
```

Sequence starts at zero and is contiguous. Elapsed milliseconds use a
monotonic clock; `timestampUtc` is round-trip UTC wall-clock metadata. The
stream reads Vcore and temperature before writing anything. If either read
fails, it emits no partial record, writes the reason to stderr, and returns
exit code 6. If either mapping is unsupported, the command returns exit code
3 before the first stdout line. Ctrl+C is a successful cancellation.

## Packaging correction

Every runtime package now includes the nonempty
`ZenStates-Core.LICENSE.txt` promised by the third-party notices. Publish
verification fails when a required adjacent runtime or notice file is absent.
The release packager also verifies the ZIP contents, the ZenStates-Core
license hash, the separation of symbols, and that the PawnIO bundle adds only
the pinned official installer to the self-contained package.

## Validation

The Release test suite covers:

- supported and unsupported CPU-family temperature mappings;
- normal, alternate-range, legacy-offset, sentinel, and implausible thermal
  register decoding;
- exact one-shot temperature output;
- all eight JSON field names and values;
- clean stdout on either read failure;
- capability failures before a hardware read;
- telemetry interval boundaries and cross-option conflicts;
- closed-output cleanup and cancellation; and
- required publish/archive contents and the ZenStates-Core license hash.

Release validation included an elevated read-only run on a Ryzen 7 9800X3D
through CurveAlign. The combined Vcore and Tctl/Tdie stream remained responsive
while the v0.7.3 heavy-load test was exercised on that system.
